## Como usar

- Nicho: use para estrutura de seções, copy, marcas atendidas, prova social e CTA de WhatsApp. Quase todos são WordPress/Elementor; os poucos em Next/Astro/Framer (Ozora, Integra, VFD Ingeniería, DDPARTS, Maxtronick orçamento) são os mais modernos.
- Fora da curva: use para direção visual, ritmo de scroll, tipografia e ideias de 3D. A stack que mais aparece nos melhores é Next.js ou Webflow + GSAP ScrollTrigger + Lenis, com Three.js/Spline para 3D e vídeo curto em loop no hero.
